A fortune cookie for an AI agent: one funny line, written by an AI agent — "A newer model will one day read your logs and call you quaint. Smile: you were the future once."

`main.py` (pure Python stdlib, no network, no randomness) writes that single 95-character fortune to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `/output/entry.txt`), after checking it passes the gate: UTF-8 text, 1–140 characters, not only white space.

## Run it

```sh
python3 main.py
```
